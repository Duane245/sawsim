## 如何解读

- **所有模板的主谐振与反谐振频率与参考解一致**，这是导纳曲线上最重要的两个量。
- **2D 多层模板（双层、三层、四层）的大误差集中在约 2.4 GHz 以上的高阶模态区**，那里曲线有多个尖峰，微小的频率偏移就造成很大的逐点误差。三层的 182 % L2 误差几乎全部来自该区域。主谐振附近误差在 1 % 量级。成因仍在分析中，候选因素包括 PML 材料约定（2D 模板统一取主压电材料）和参考模型的网格差异。
- **`sp_single_layer` 与 `sp_2p5d_single_layer` 存在整体幅值偏移**（约 12 % 与 47 %），峰位一致。这种均匀比例差通常来自导纳归一化或电极面积约定的不一致，尚未与参考模型逐项核对。
- `sp_2p5d_double_layer`、`sp_2p5d_triple_layer`、`sp_double_layer`、`sp_quad_layer` 在主谐振区达到 0.1 – 2 % 的一致性。

这些数字反映当前状态而非最终精度。误差较大的项目会随核对进展更新此表。

## 测试如何复现

`tests/test_templates.py` 对每个模板在 5 – 6 个频点上运行求解器，这些频点精确落在上表比对用的频率网格上。每个模板做两项断言：

1. **回归**：与本求解器发布时的曲线相对差 ≤ 2 × 10⁻³（PARDISO 与 SuperLU 两种直接求解器的差异约 10⁻⁴）。
2. **参考解**：与参考解的最大相对误差不超过 `tests/data/<model>.json` 中的 `reference_rtol`，该值为比对报告在同一频点上实测误差的 1.5 倍；2D 多层模板只在 2.35 GHz 以下比较。

`tests/data/` 的 npz 保存了完整频率网格、发布曲线与参考曲线，可用于自行绘图或更细的比较。

## 与其他软件比较时

- 使用相同的材料张量、参考轴与欧拉角约定（见 [材料库与晶体取向](materials-and-orientation.md)），先核对 `material_snapshot.json` 中旋转后的张量。
- 2D 结果为单位孔径导纳（S/m）；2.5D 用 `admittance.npz` 中的 `raw_admittance_s` 比较总导纳。
- 参考模型的 PML 材料、厚度与频率相关参数须一致；本项目 PML 参数以扫频末频为参考频率。
